# Vidéo TikTok « Une photo → son livre de Noël » (HyperFrames)

Vidéo verticale 1080×1920, 15 s, faite à partir du livre de démonstration de Léo (enfant fictif).

- Modifier : `index.html` (textes, durées, images dans `assets/`).
- Vérifier : `npx hyperframes@0.9.23 check`
- Fabriquer la vidéo : `npx hyperframes@0.9.23 render -o tiktok.mp4` (Node 22+, FFmpeg et Chrome sur l'ordinateur).

HyperFrames (Apache-2.0) : https://github.com/heygen-com/hyperframes
